# Collection coverage and remaining gaps

Status checked November 9, 2026. This is an acquisition log, not a claim that every source in any jurisdiction has been discovered or assessed. See [README.md](README.md) and the manifests for provenance and methods.

Seventeen new state/regional GIS snapshots were reconciled to source feature counts; see each directory's `snapshot.json`. These checks do not prove their geographic accuracy or currency.
- Twenty-one additional Indiana, Massachusetts, Ohio and Vermont GIS snapshots contain 523,583 source features across 537 compressed pages. Count and checksum checks do not establish completeness in the real world.
